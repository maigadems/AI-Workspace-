# Plateforme IA pour collaborateurs

## Description

Ce projet vise à créer une plateforme web interne permettant à des collaborateurs d’utiliser différents services d’Intelligence Artificielle depuis une interface unique.

L’objectif principal est de concevoir l’interface utilisateur avant le développement des modèles IA eux-mêmes. La partie front-end doit permettre de communiquer ensuite avec les APIs disponibles.

## Stack technique

- HTML
- CSS
- JavaScript
- Aucun framework

## État actuel du projet

Le dépôt contient la structure de base du front-end :

- `index.html` : point d’entrée de l’application
- `css/style.css` : styles de l’interface
- `js/script.js` : logique JavaScript

À ce stade, le projet est en phase de mise en place de la structure et de conception de l’interface utilisateur.

## Structure du dépôt

```text
AI-Workspace/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
```

## Prérequis

- Un navigateur web moderne
- Un éditeur de code (VS Code recommandé)

## Lancer le projet

1. Ouvrir le fichier `index.html` dans un navigateur moderne.
2. Si nécessaire, utiliser un serveur local simple pour tester la page dans un environnement web.

La page peut être consultée directement depuis le système de fichiers, sans installation supplémentaire.

## Objectif fonctionnel

La plateforme devra permettre :

- de sélectionner un service IA
- de saisir une demande ou une requête
- d’afficher le résultat généré
- de proposer une interface claire et ergonomique pour les utilisateurs internes
